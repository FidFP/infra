# Demande à Silicom - préparation réseau Dr.Tax

## Objet

Préparation réseau pour une installation Dr.Tax centralisée sur PC1

## Message proposé

Bonjour,

Nous préparons une installation réseau de Dr.Tax. PC1 hébergera le serveur
applicatif et la base de données ; PC2 accédera au client depuis le réseau local.

Pouvez-vous s'il vous plaît :

1. confirmer que PC1 et PC2 peuvent communiquer sur le même réseau ou entre les
   VLAN concernés ;
2. confirmer ou créer une réservation DHCP pour l'interface réseau utilisée par
   PC1 ;
3. confirmer que le nom de PC1 est correctement résolu depuis PC2 ;
4. nous indiquer si des règles réseau centrales doivent être adaptées pour les
   ports Dr.Tax, SQL/PostgreSQL et le partage de fichiers qui seront définis à
   partir de la documentation officielle lors de l'installation ;
5. confirmer qu'aucun de ces ports ne sera publié directement sur Internet.
